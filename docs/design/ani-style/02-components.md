# 02 · 共用组件

> 本文定义 C1–C21 的视觉规格。颜色、字级、圆角只写 token 与样式名(见 01)。
> 适用平台:iOS 与 macOS(05 §8.1)。
> 实现方式:**新增** Apple 版组件,调用处按 `LocalPlatform.current.isApple()` 选择;既有组件原样保留给 Android、Windows、Linux。不改组件背后的状态与回调语义。

---

## 0. 通用约定

- 尺寸单位 dp,字号单位 sp;「W600」指字重。
- 点击区域至少 44×44(手机)/ 28×28(macOS)。视觉小于此尺寸的按钮,外围补透明点击区。
- 图标统一用线条图标,线宽 1.8–2.2;选中态可加粗或改实心。
- 本文的「深色」「浅色」只描述 token 选择,具体色值见 01 §2。

## 手机组件

### C1 FloatingTabBar 浮动胶囊导航栏

| 属性 | 值 |
|---|---|
| 位置 | 悬浮于内容上方:左右各 16,距底部 20 + 系统底部安全区 |
| 尺寸 | 高 64,圆角 32,左右内距 8 |
| 底色 / 阴影 | 实心 tabBg;floatingShadow(深色加 1dp separator 描边)。**不读取**「毛玻璃效果」设置，开关开或关都是实心底 |
| 项目 | 平均分宽;图标框 36×36 + 文字,间距 2 |
| 未选中 | 图标 24、线宽 1.8、label2;文字 tabLabel W500、label2 |
| 选中 | 图标框圆角 18、底 tint、内描边 1.5 accent;图标 22、线宽 2、accent;文字 W700、accent |
| 项目顺序 | 探索、追番、快取、我的(「我的」见 05 B1) |

- 内容区底部要留出 64 + 20 + 16 的空白,最后一项不能被遮住。
- 实现位置:`ui-adaptive` 的 `NavigationSuite` / `AniNavigationSuiteScaffold`。新增 Apple 版 FloatingTabBar 与 Apple 版 rail(iPad 宽屏,按 token 配色,含「我的」,05 G12),调用处按 `isApple()` 选择;原 `NavigationBar`、`NavigationRail` 不改,其他平台照旧。
- **显示规则**:主要分页显示;推入的内容页(条目详情、新番时间表、排行、播放记录、快取详情、人物/角色、通知、设定子页)也显示;全屏任务(播放、搜索、资料源编辑器、登录/授权/扫码、头像裁剪、编辑个人资料、合并收藏)隐藏。
- **推入页的高亮**:高亮来源分页,即返回栈中最近的主分页,不按页面类型写死。点其他分页回到主页面并切换;点当前高亮的分页回到该分页的根页面。实现要点见 05 §8.5(G10),仅 iOS。

### C2 LargeTitleHeader 大标题页头

- 手机:顶部安全区下 14 起;一行内左侧 `largeTitle`,右侧动作按钮(C8 圆形按钮 36、fill 底)。Apple 平台的页头不放头像按钮(05 G14)。标题下 18 开始内容。
- macOS:内容区顶部 4 起;`macLargeTitle`,可在同一基线后接 `macCallout` label2 的副标题(间距 12)。

### C5 GroupedListCard 分组列表卡

- 卡片:card 底,圆角 16(macOS 14),裁切内容。
- 行间分隔线:1dp separator、opacity 0.6;从文字起点(图标或封面右侧)开始,延伸到卡片右缘。
- 分组标题:`footnote` label2,左右内距 16(macOS 12),与卡片间距 8;分组之间 24。
- 分组下方说明:label2;手机 `footnote`、内距 8 16 0;macOS `macCaption`、内距 8 12 0。

### C11 AvatarRing 品牌头像光环

- 圆形,底 `AniColors.brandSlate`,首字母白色粗体。
- 光环 = 内圈间隙(当前背景色)+ 外圈 `AniColors.brandRing`。
- 头像尺寸(间隙、光环):
  - 手机「我的」页个人卡 60(2.5、2.5);手机编辑个人资料 88(3、3)。
  - macOS 侧边栏帐号行 28(2、1.5);设定窗口分类栏帐号行 32;设定窗口帐号窗格 64;macOS 编辑个人资料 64。
  - Apple 平台页头不放头像(05 G14),不再有 34 号。
- 品牌标志(石板圆 + 光环 + 中间 brandRing 播放三角),间隙 3、光环 3:
  - 手机登录 76;手机关于 76。
  - macOS 登录 72;macOS 关于 64(间隙为 card 色)。
  - macOS 扫码面板 QR 中央 40。
- 软件更新的新版本卡用 **52 App 图标**,不是圆形光环:52×52、圆角 14、brandSlate 底,中央 22 圆环(3.5 宽 brandRing)。手机与 macOS 相同。

### C18 MacToolbar 工具栏

- 高 52,内距 0 20 0 16。
- 左侧上一页 / 下一页按钮 28(不可用时 opacity 0.35)。
- 右侧本页动作:图标按钮 28;文字按钮高 28、圆角 6、fill 底;分段切换按钮被选中时 tint 底 + accent 图标。

### C19 MacTable 表格

- 容器:card 底、圆角 14、裁切。
- **表头与每一行共用同一组列宽**(用同一个 `grid` 列模板或同一组固定宽度),对齐方式按列统一,左右内距相同(16–24)。
- 表头:高 32–36,`macCaption` W500 label2,底部 1dp separator;当前排序列为 label W600 + 11 号 ↓。
- 行:高 52–76;分隔线从第一个内容列起点开始,opacity 0.6;选中行 tint 底。
- 分组行(如「进行中 3」「已完成 8」):高 32、bg 底,左侧标题 13 W600 + 数量 label2,右侧动作文字或合计;**右侧内容与下方操作列同宽、同中线**。
- 表格下方可放一行 `macCaption` label2 操作提示(双击、⌘I、右键)。

### C20 MacSettingsWindow 设定窗口

- 920×680。左侧分类栏宽 232,底 `AniColors.sidebar`,内距 0 12:顶部系统红黄绿区;账号行(内距 8 10、圆角 8;C11 32 号 + 名称 13/18 W600 + 「账号与同步」11/14 label2;选中 tint 底);账号行下 16 起是四组分类:
  - 应用与界面:界面、主题与色彩、通知
  - 资料源与播放:播放器和弹幕过滤、资料源管理、观看偏好
  - 网络与存储:服务器区域、代理、BitTorrent、存储
  - 其他:软件更新(有新版本时 C12)、日志、关于、设定备份;除错模式开启时加「除错」
- 分组标题:11/14 W600 label2(`macSidebarSection`),内距 0 10 4;组与组之间 12。
- 分类项:高 28、圆角 6、内距 0 10;16 号图标 + 间距 8 + 13/18 文字(`macCallout`);项与项之间 1。
- 分类项选中:tint 底 + onTint W600 + accent 图标(配色同 C17;尺寸以本节为准,比 C17 的项目小)。
- 右侧窗格:标题栏高 52、`macWindowTitle`;内容左右 28;分组用 C5(圆角 14)、行用 C6 macOS 规格。
- 子页(Bangumi 同步、Peer 过滤):分类栏保持父分类选中;标题栏左侧放返回按钮「‹ 父页名」,样式统一为次要按钮(fill 底、高 28、圆角 6)。

### C21 Inspector 检阅器

- 主内容右侧,宽 320,底 `AniColors.sidebar`,左侧 1dp separator,内距 12 16 16。
- 顶部:`macWindowTitle` 标题 + 24 号关闭按钮。内容为 card 底小卡片。
- 由工具栏按钮或 ⌘I 开关(05 C3);打开时工具栏按钮为 tint 底,左侧表格隐藏次要列。
- 标题用 `macWindowTitle`(15/20 **W600**),各页不要另写成 W700。
