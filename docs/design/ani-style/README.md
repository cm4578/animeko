# Ani 风格界面实现方案(iOS 与 macOS)

> 状态:**方案已定**,待实现。日期:2026-10-31。
> 适用平台:**本期只做 iOS(iPhone、iPad)与 macOS**(Desktop JVM 运行在 macOS 时)。Android、Windows、Linux、Android TV **维持现状**,之后另行设计。唯一例外是 zh-TW 字串修正,各平台共用。
> 视觉参考:Claude Design 画布「Ani 配色重选」——「定案画面」页(手机)、「macOS」页、「配色与元件」页(元件原稿)。画布仅维护者可打开,执行时不需要打开;画板与本文不一致时,**以本文为准**。

## 0. 给执行 Agent 的硬性规则

1. **不重写既有 Function 和功能。** 本方案默认只改 UI 层:Composable 的版式、样式、配色、字级。ViewModel、Repository、数据模型、设置项的存储格式与语义、导航逻辑都不改。
2. **例外只有 [05-approved-changes.md](05-approved-changes.md) 列出的项目**,它们已获维护者批准,按该文范围实现,不扩大。
3. **其他任何需要改逻辑、加功能、加设置项、加数据请求的地方,停下来询问维护者**,不要自行决定。撰写时发现的此类项目已于 2026-10-31 答复,结论见 05 §8;实现中再遇到未列出的,照此规则询问。
4. **平台闸门:** 新版型以**新增**的 Apple 版 Composable 实现,调用处按 `LocalPlatform.current.isApple()`(新增于 `Platform.kt`)选择。**既有 Composable 不改**,原样留给 Android、Windows、Linux。配色只在 iOS 与 macOS 的 `appColorScheme` 生效(01 §9)。macOS 专属的窗口、菜单列、快捷键用 `isMacOS()`。
   - 新增的数据读取一律写成冷流(`WhileSubscribed`),只有 Apple 版画面订阅时才启动(05 §8.1)。
   - 新文案一律新增字串 key,四个语言目录同时加入;既有字串只在 05 D4 范围内改(05 §8.3)。
5. 遵守仓库 `AGENTS.md`:用 import 不写全限定名;`commonTest` 反引号测试名只用英文字母、数字、空格、`-`、`_`;注释描述当前设计,不写「改为…」「不再…」;截图按「UI Verification」一节上传为 GitHub 附件,不进仓库。
6. 每个 PR 只做一个阶段(§2),PR 描述里列出对照的本文章节和画板名称。

## 3. 设计原则(所有页面通用)

- **品牌**:App 图标的石板色 `#2F3943` 加天空蓝光环 `#7EBBED`。深色模式是「石板夜色」(带一点蓝的深灰,不是纯黑)。
- **少用功能色**:
  - accent(品牌蓝)只用于**动作**和**当前位置**:主要按钮、链接文字、选中的分页、正在播放的集数、进度。
  - alert(橙红)只用于**新内容/未读提示点**。
  - error(红)只用于**错误状态**(下载失败、测试失败、格式错误)。
  - **危险操作不用红色**(删除下载、删除账号、拒绝、解除绑定、登出),由确认对话框防误触。
- **文字层级**只用三级:label(主要)、labelSoft(次一级)、label2(次要)。不额外加颜色。
- **选中态**统一用 tint 淡底 + onTint 文字(胶囊分页、选中行、当前集)。
- **同质项目用列表或表格**,卡片内放列表行,行间 inset 分隔线(opacity 0.6)。
- **封面**:内容卡与搜索、排行等列表用 3:4;追番网格用 2:3。不放宽度小于 42px 的缩略图。
- **间距**:8pt 栅格。iPhone 页面左右 16;macOS 内容区左右 32。
- **对齐**:表格的表头与每一行共用同一组列宽;同一列的对齐方式一致;左右内距对称。
- **就地执行的动作行**(复制、导入、登出、检查更新)用 accent 文字;进入下一页用 `›`;外部链接用 `↗`。
- **设定子页的行不放图标小方块**;只有「我的」页(macOS 为设定窗口分类栏)的分类入口带图标。

## 5. 验证

### 5.1 自动化

- 01 §10 的单元测试全部通过。
- 受配色影响的截图测试按仓库流程更新金图,PR 中说明。
- 各目标编译通过(Android、iOS、Desktop);Android 与 Windows/Linux 的画面不受影响。

### 5.2 手动验证

macOS 用仓库技能 `.agents/skills/desktop-ui-verify`;iOS 用模拟器;Android、Windows 各抽查一次确认未受影响。每项浅色、深色都要看:

- [ ] 页面背景、卡片、导航(手机浮动胶囊导航栏 / macOS 侧边栏)
- [ ] 没有残留的紫色或泛色调背景(搜索 `surfaceTint`、`tonalElevation`、写死的 `Color(0x…)`)
- [ ] 每一层的页面与画板逐一对照,记录差异
- [ ] 主题色切换到其他预设色、开启「条目页动态主题」时,背景仍为中性石板色
- [ ] 高对比度深色主题开启时为纯黑背景,次要文字(label2)仍是灰色
- [ ] 推入页的导航高亮跟随来源分页(iOS 浮动导航栏、macOS 侧边栏)
- [ ] Android、Windows、Linux、Android TV 的外观与导航和改动前一致(只有 zh-TW 文字不同)
